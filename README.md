# 🔬 ResearchFlow AI

A modular multi-agent research assistant built with:

- CrewAI
- Groq
- GPT-OSS 120B
- Streamlit
- Serper Web Search

## Agents

1. Researcher
2. Analyst
3. Fact Checker
4. Report Writer

## Workflow

Research → Analysis → Fact Check → Report

## Features

- Multi-agent research
- Web search
- Numerical calculations
- Fact checking
- Professional Markdown reports
- Streamlit interface
- Downloadable research report
